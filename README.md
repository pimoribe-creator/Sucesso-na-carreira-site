# Sucesso na Carreira — site

Site do curso Sucesso na Carreira, de Paulo Moribe (versão H3 aprovada em 11/11/2026).

- `index.html` — página principal
- `privacidade.html`, `termos.html`, `contato.html` — textos legais
- `oferta.json` — **painel de controle**: preço, parcelamento, link da Hotmart, e-mail, endereço, vídeos do YouTube e pixel da Meta. Para mudar qualquer um deles, edite só este arquivo.
- `assets/` — estilo, script, fontes (hospedadas aqui, sem Google) e a foto
